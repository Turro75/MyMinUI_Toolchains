This repo is used to store some toolchain blobs useful to speed up toolchain creation:

my282_toolchain.tar.gz  -> toolchain blob to be used with miyoo a30 as target

m21_toolchain_glibc.tar.gz  -> toolchain blob to be used with sjgam m21 as target (MyMinUI chroot)
m21_toolchain_musl.tar.gz  -> toolchain blob to be used with sjgam m21 as target (native)

rg35xx_toolchain.tar.gz  -> toolchain blob to be used with anbernic rg35xx (not 2024) as target (MyMinUI chroot)

r36s_toolchain_glibc.tar.gz  -> toolchain blob to be used with arkos on anbernic rg353x and gameconsole r36s as target
